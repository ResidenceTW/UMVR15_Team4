# 🎮 幻影之星｜第三人稱 ARPG 玩家角色控制器模組（Unity + C#）

本模組為Unity製作的第三人稱ARPG遊戲《幻影之星》，組員陳彥均負責項目為角色控制核心，搭配自訂狀態機與武器模組，整合玩家移動、近戰連段、瞄準射擊、血量與能量系統、動畫控制與敵人鎖定等，打造一套具有延展性與商業實用性的遊戲控制框架。

---

## 功能簡述

| 模組 | 功能 |
|------|------|
| "PlayerController.cs" | 核心控制器，綜合輸入、動畫、狀態旗標、角色動作切換邏輯 |
| "PlayerStateMachine.cs" | 自訂輕量級狀態機框架，負責管理狀態切換 |
| "PlayerState.cs" | 所有狀態的抽象基底類別，統一接口 |
| "IdleState.cs" | 靜止狀態，檢測輸入自動切至移動或戰鬥 |
| "MoveState.cs" | 行走與奔跑邏輯，依據輸入與奔跑鍵切換速度 |
| "AimState.cs" | 瞄準狀態，角色面向攝影機方向，支援滑鼠旋轉與開槍 |
| "FightState.cs" | 攻擊狀態，包含近戰 Combo、旋轉鎖定敵人、跳砍機制 |
| "DeadState.cs" | 死亡狀態，阻止一切操作並播放動畫 |
| "AnimatorController.cs" | 動畫層級控制器，透過事件與狀態切換驅動動畫行為（連擊、Dash、受傷等） |
| "LockOnIndicator.cs" | UI 控制腳本，顯示並追蹤被鎖定敵人的畫面指示器 |
| "CameraController.cs" | 負責第三人稱攝影機的旋轉、視角控制與鎖定鏡頭切換 |
| "WeaponManager.cs" | 管理武器攻擊時段、觸發 hitbox、連段攻擊與特效生成 |
| "GunSystem.cs" | 處理射擊邏輯、PP 消耗、開火動畫與槍口閃光等效果 |
| "PlayerHealth.cs" | 控制玩家血量、PP 消耗與恢復、死亡與復活邏輯 |
| "LevelSystem.cs" | 管理玩家升級、經驗累積與屬性成長機制 |
| "PlayerDataSO.cs" | ScriptableObject：集中管理角色屬性（攻擊力、防禦、速度等） |
| "GameManager.cs" | 遊戲總管理器，提供全域控制、單例存取與核心流程管理 |

---

## 技術亮點

- ✅ 自製狀態機結構，所有角色行為模組化、可擴充
- ✅ 完整瞄準系統，支援自由視角與鎖定轉換、UI同步
- ✅ 攝影機多模式切換：自由視角、越肩瞄準、BOSS 鎖定旋轉
- ✅ 武器系統支援 Combo、瞬移砍擊、Slash 特效生成與敵人範圍打擊
- ✅ 射擊系統整合 PP 資源消耗、射線判定與後座動畫
- ✅ 血量與PP並存，具備復活邏輯、持續回覆與特效呈現
- ✅ 等級成長可自定公式，升級時自動更新血量／攻擊力／PP／UI
- ✅ 所有模組均可讀取 `PlayerDataSO`，集中管理屬性與Layer設定
